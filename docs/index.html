Слой построен из OCR распознанных таблиц, поэтому часть значений неизбежно содержит ошибки распознавания. Они не удаляются, а помечаются: исходная ячейка остаётся доказательством, а решение принимает исследователь.

Как свойство опознано в заголовке

symbol_embedded — химический символ найден внутри более длинного заголовка («Thickness of horizons, cm A + B»). Такие значения следует исключать из анализа по умолчанию.

Физическая правдоподобность значений

Проверка диапазона запускается только там, где единица действительно известна. pH проверяется всегда — он безразмерен.

Допуск кандидатов в слой наблюдений

Кандидат из OCR-таблицы становится наблюдением только после согласованной трёхагентной проверки происхождения и доказанной единицы измерения; accepted — кандидат допущен, rejected — отклонён или оставлен в очереди ручного разбора.

Сила пространственной привязки

Вся база наблюдений загружается в браузер и выполняет SQL локально — данные никуда не отправляются. Таблицы: observation, reported_site, verified_measurement, meta.

Загрузка базы…

Доказательная цепочка

Каждое наблюдение прослеживается до конкретной ячейки:

document → source_artifact → table_cell → table_measurement_candidate → table_observation

Поле evidence_locator хранит номер строки и колонки исходной таблицы, напечатанный заголовок свойства и метку строки.

Чего эти данные не утверждают

  • Наблюдение попадает в базу только после того, как его единица измерения доказана (напечатана в заголовке/подписи или получена обратимым преобразованием) и прошла согласованную трёхагентную проверку происхождения; кандидаты без доказанной единицы остаются в очереди ручного разбора.
  • Единственная координата в статье — это контекст документа, а не GPS каждой строки таблицы.
  • pH(H₂O), pH(KCl) и pH без указания метода — три разных показателя.
  • В document_links.csv — 966 связей между документами: 625 пар «русский оригинал ↔ перевод в Eurasian Soil Science» (608 по печатной ссылке, 17 по отпечатку значений) и 341 связь «прежний импорт РЦСИ ↔ новый OCR-импорт того же источника». Документы не объединяются. Верхняя граница риска двойного учёта для остальных статей «Почвоведения» — 6.8% слоя.
  • Набор точек не является вероятностной выборкой по территории России.

Воспроизведение

Все публикуемые файлы пересобираются из рабочей базы одной командой:

python3 observatory_v1/extract_table_measurement_candidates.py --db DB --additive
python3 observatory_v1/normalize_table_measurement_candidates.py --db DB
python3 observatory_v1/materialize_full_table_observations.py --db DB
python3 observatory_v1/flag_observation_quality.py --db DB
python3 observatory_v1/infer_springer_publication_year.py --db DB --crossref docs/data/doi_metadata.csv
python3 observatory_v1/infer_document_study_region.py --db DB
python3 observatory_v1/infer_document_precise_coordinates.py --db DB
python3 observatory_v1/merge_spatial_layers.py --db DB
python3 observatory_v1/link_springer_translations.py --db DB
python3 docs/scripts/build_portal.py --db DB --output docs/data

Полная последовательность, включая сборку научного анализа и отчётов, — в README.md репозитория. Текущий рабочий снимок дополнительно прошёл трёхагентную ручную сверку происхождения и единиц измерения (2026-08-06 — 2026-08-09), не сводимую к одной команде; журнал — в docs/database_rebuild_note.md и docs/recovery_journal_2026-08-09.md.
