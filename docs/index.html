Что показано: только координаты, прямо сообщённые авторами публикаций. Синие точки дополнительно имеют числовые значения, сверенные с исходной OCR-ячейкой. Административные центроиды и региональные геокоды на карту не выводятся. Это не GPS-привязка каждой строки таблицы и не почвенная карта России.

Слой построен из OCR распознанных таблиц, поэтому часть значений неизбежно содержит ошибки распознавания. Они не удаляются, а помечаются: исходная ячейка остаётся доказательством, а решение принимает исследователь.

Как свойство опознано в заголовке

symbol_embedded — химический символ найден внутри более длинного заголовка («Thickness of horizons, cm A + B»). Такие значения следует исключать из анализа по умолчанию.

Физическая правдоподобность значений

Проверка диапазона запускается только там, где единица действительно известна. pH проверяется всегда — он безразмерен.

Сила пространственной привязки

Вся база наблюдений загружается в браузер и выполняет SQL локально — данные никуда не отправляются. Таблицы: observation, reported_site, verified_measurement, meta.

Загрузка базы…

Доказательная цепочка

Каждое наблюдение прослеживается до конкретной ячейки:

document → source_artifact → table_cell → table_measurement_candidate → table_observation

Поле evidence_locator хранит номер строки и колонки исходной таблицы, напечатанный заголовок свойства и метку строки.

Чего эти данные не утверждают

  • Значение со статусом missing_unit не имеет подставленной «по смыслу» единицы.
  • Единственная координата в статье — это контекст документа, а не GPS каждой строки таблицы.
  • pH(H₂O), pH(KCl) и pH без указания метода — три разных показателя.
  • Русский оригинал и его перевод в Eurasian Soil Science не объединены: доказанного соответствия между ними пока нет.
  • Набор точек не является вероятностной выборкой по территории России.

Воспроизведение

Все публикуемые файлы пересобираются из рабочей базы одной командой:

python3 observatory_v1/extract_table_measurement_candidates.py --db DB --replace-existing
python3 observatory_v1/normalize_table_measurement_candidates.py --db DB
python3 observatory_v1/materialize_full_table_observations.py --db DB
python3 observatory_v1/flag_observation_quality.py --db DB
python3 observatory_v1/infer_springer_publication_year.py --db DB
python3 docs/scripts/build_portal.py --db DB --output docs/data
